# Motion2Video Pro — Dark

**نسخهٔ ۱.۳.۱ • ساخته‌شده با امضای Dark**

استودیوی فارسی اندروید برای واردکردن HTML موشن، پیش‌نمایش و رندر ویدیو. رابط تک‌فایل HTML با GSAP، Tailwind، فونت فارسی، لوگوی برداری و چیدمان موبایل همراه پروژه است.

## قابلیت‌ها

- پیش‌نمایش HTML / CSS / SVG / GSAP و کنترل فریم‌به‌فریم.
- خروجی اصلی H.264 در MP4 با FastStart، YUV420P و BT.709 limited.
- انتخاب 30/60fps، اندازه‌های 360p تا 1080p و عمودی، بیت‌ریت 12/16/20Mbps.
- HEVC/AV1 و VP8/VP9 وابسته به کدگذار گوشی؛ VP8/VP9 در WebM ذخیره می‌شوند.
- ذخیرهٔ خودکار در `Download/Motion2Video/`؛ فهرست دانلودها با نام، مسیر، حجم و دکمهٔ بازکردن فایل یا دانلودهای گوشی. نام فایل `Motion2Video_yyyyMMdd_HHmmss_SSS_xxxxxx.mp4` است.
- فونت‌های محلی Vazirmatn، Amiri معمولی/ضخیم، Noto Naskh Arabic، Scheherazade New، Anton و Inter.
- GSAP و پنج افزونه، Lottie و Three.js همراه مجوزها و اعلان‌های اصلی.

خروجی اندروید فعلاً **بی‌صدا** است. همهٔ کدک‌ها/رزولوشن‌ها روی همهٔ گوشی‌ها پشتیبانی نمی‌شوند. ProRes/MOV/alpha در APK پیاده نشده‌اند. ابزار اختیاری `desktop/master_export.py` برای تبدیل و ترکیب صدا به FFmpeg نصب‌شده روی کامپیوتر وابسته است.

## نصب

APK آماده در [بخش Releases](https://github.com/imthedark-dark/motion2video-pro/releases/tag/v1.3.1-dark) در دسترس است. حداقل Android 8 (API26) لازم است. APK آزمایشی است. منابع دانلودشده از GitHub Actions یا ساخته‌شده روی کامپیوتر دیگر، کلید آزمایشی مستقل دارند؛ برای ارتقای نصب فعلی از APKهای انتشار همین پروژه استفاده کنید. کلید خصوصی انتشار در مخزن نیست.

## ساخت از سورس

JDK17+، Python3، Android SDK Platform35 و Build Tools35.0.0 را نصب کنید. سپس:

```sh
export ANDROID_SDK_ROOT=/path/to/Android/Sdk
python3 build.py
```

APK امضاشدهٔ آزمایشی در `dist/` تولید می‌شود. `build/debug.jks` فقط روی دستگاه سازنده ایجاد می‌شود و توسط Git نادیده گرفته می‌شود. رمز استاندارد `android` در اسکریپت مربوط به این کلید آزمایشی عمومی است؛ کلید واقعی یا رمز خصوصی انتشار داخل کد نیست. پروژه را می‌توان در Android Studio هم باز کرد؛ Gradle8.9 / AGP8.7.3 لازم است.

## رابط و ساختار

- `ui/Motion2Video-Studio.html`: سورس اصلی و تک‌فایل رابط؛ امضای Dark در پایین صفحه دیده می‌شود.
- `app/src/main/java`: برنامه، MediaCodec/MediaMuxer، اصلاح رنگ/FastStart، ذخیره و بازکردن دانلودها.
- `app/src/main/assets`: فونت‌ها، کتابخانه‌ها، ساعت انیمیشن و کپی رابط برای APK؛ هر ساخت کپی رابط را به‌روز می‌کند.
- `desktop/`: ابزار اختیاری FFmpeg.
- `tools/check_updates.py`: فقط بررسی نسخهٔ کتابخانه‌ها؛ جایگزینی خودکار انجام نمی‌دهد.
- `tests/`: آزمون رابط/ساعت انیمیشن و سورس instrumentation اندروید.

رابط مورد اعتماد و HTML کاربر در WebViewهای جدا اجرا می‌شوند؛ ارتباط رابط با رندر از MessagePort انجام می‌شود و JavascriptInterface به کد موشن داده نمی‌شود. دارایی‌های شناخته‌شده در APK محلی‌اند؛ HTML مستقل مرورگر برای CDNها اینترنت می‌خواهد. ضبط MP4 مرورگر به پشتیبانی MediaRecorder، ضبط تب و Region Capture وابسته است و معادل رندر فریم‌به‌فریم اندروید نیست. نصب PWA هم به مرورگر و مبدأ امن وابسته است.

## دانلودها و دسترسی‌ها

Android10+ از MediaStore.Downloads با فایل pending تا پایان کپی استفاده می‌کند. Android8/9 برای نوشتن در دانلودها دسترسی حافظه می‌خواهد؛ مجوز دسترسی کلی به همهٔ فایل‌ها درخواست نمی‌شود. فهرست برنامه فقط خروجی‌های ثبت‌شدهٔ خودش است، پس از بستن برنامه باقی می‌ماند و جابه‌جایی/حذف بیرونی هنگام بازکردن با خطا مشخص می‌شود. اگر فایل‌منیجر پوشهٔ مشخص را مستقیم باز نکند، صفحهٔ دانلودهای سیستم نمایش داده می‌شود.

## آزمون

```sh
npm ci
npx playwright-core install chromium
npm run test:ui
npm run test:clock
```

برای Chromium نصب‌شدهٔ سیستم، `CHROMIUM_PATH` را به فایل اجرایی مرورگر تنظیم کنید. آزمون رابط شامل موبایل/دسکتاپ، پیام‌های ذخیره، مسیر/نام، فهرست دانلودها و بازکردن فایل/پوشه با پل شبیه‌سازی‌شده است. آزمون ساعت، API جدید و fallback CSS را بررسی می‌کند.

رندر واقعی یک کلیپ فارسی/عربی/انگلیسی 360p30 روی شبیه‌ساز Android11 در نسخهٔ ۱.۲ بررسی شد؛ نمونهٔ کوچک در `tests/fixtures/` است. مسیر جدید ذخیرهٔ MediaStore/Android8/9 نسخهٔ ۱.۳ هنوز آزمون اجرایی اندروید نشده است. گوشی واقعی، همهٔ کدک‌ها، 1080p60 و WebGL آزمون پذیرش نشده‌اند.

## حریم خصوصی و مجوزها

کلید امضا، توکن، تنظیمات محلی، لاگ محیط و دادهٔ کاربر وارد مخزن نمی‌شوند. کد HTML واردشده برای رندر به سرور برنامه ارسال نمی‌شود؛ منابع خارجی خود HTML می‌توانند شبکه استفاده کنند. مجوز فونت‌ها و اعلان‌های کتابخانه‌ها در `assets` حفظ شده‌اند؛ توضیح بیشتر در `THIRD_PARTY_NOTICES.md` است.
